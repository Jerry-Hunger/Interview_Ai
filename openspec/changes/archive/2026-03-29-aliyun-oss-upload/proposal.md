# Proposal: 阿里云 OSS 简历和图片上传功能

## Why we're doing this

用户需要上传个人简历和头像图片，当前系统使用 Firebase 配置但未实际使用，且简历内容仅存储为文本。为了支持文件上传功能，需要接入阿里云 OSS 实现稳定可靠的文件存储服务。

## What's changing

1. **接入阿里云 OSS** - 替换未使用的 Firebase 配置，使用阿里云 OSS 存储用户上传的文件
2. **头像上传功能** - 用户可以上传头像图片
3. **简历文件上传** - 用户可以上传 PDF/DOC/DOCX 格式的简历文件
4. **新建简历数据模型** - 创建独立的 Resume 模型存储简历文件信息和解析后的文本内容

## Non-goals

- 不保留现有的 resumeText 纯文本字段
- 不实现图片裁剪、压缩等高级功能
- 不实现前端直传（使用后端中转模式）

## Success criteria

- [x] 用户可以上传头像图片并成功显示
- [x] 用户可以上传简历文件并保存到 OSS
- [x] 上传的文件可以在用户资料页面查看
- [x] 文件类型和大小限制正常工作
- [x] API 接口返回正确的文件访问 URL
