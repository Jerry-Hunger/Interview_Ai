# Proposal: 企业学生功能增强与职位筛选

## Why we're doing this

1. 企业用户需要展示公司形象，包括 Logo、环境照片、公司简介等信息
2. 学生用户需要维护完整的个人资料
3. 学生浏览职位时需要通过多维度筛选找到目标公司
4. 需要为 GitHub OAuth 登录做准备

## What's changing

### 企业端
1. 企业用户头像/Logo 上传功能
2. 公司环境照片上传功能（多张）
3. 公司信息管理页面（简介、办公地点、坐标、官网）

### 学生端
1. 个人信息维护功能扩展（姓名、手机、所在地、期望薪资）
2. 职位浏览页面增加筛选功能（按企业、职位类型、面试轮次、面试类型）

### 登录
1. 登录页面添加 GitHub 登录按钮（预留 OAuth 接口）

## Success criteria

- [ ] 企业可以上传和管理公司 Logo
- [ ] 企业可以上传多张环境照片
- [ ] 企业可以维护公司基本信息
- [ ] 职位信息显示企业相关信息
- [ ] 学生可以修改个人资料
- [ ] 学生可以通过多维度筛选职位
- [ ] 登录页面显示 GitHub 登录按钮
